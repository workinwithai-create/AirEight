# AirEight

Eight-bar verse air desk for bedroom producers and AI-music finishers.

Suno and loop DAWs fill every lane in the verse. The hook has nowhere to lift because the verse is already as full as the chorus. Session players leave rests, thinner voicings, and open kit patterns in the verse so the hook can arrive by contrast, not just by turning the fader up.

Live samples only — FluidR3 piano, upright bass, nylon guitar, and acoustic kit loaded from the PreEight sample bank pinned to commit `d58301e4a494555f411a2afbc448b724136eee76`. No oscillators. No `@main`.

## Distinct from the line

| Tool | Job |
| --- | --- |
| MuteEight | Subtract from the *chorus* so the drop feels different |
| PreEight | Eight bars of musical climb *before* the hook |
| TagFour | Four bars after the last chorus |
| StackEight | Add voices to an existing chorus chord |
| **AirEight** | Thin the *verse* so the hook has room to lift |
